## 0. 규격 / 좌표 기준

- 슬라이드: **16:9, 13.333″ × 7.5″** (12192000 × 6858000 EMU)
- 렌더 기준 픽셀: 1600 × 900 px → **120 px/inch** (px ÷ 120 = inch)
- 폰트: **Pretendard** (Regular/Medium/SemiBold/Bold) → pptx 에 **임베딩 필수** (없으면 대체폰트로 레이아웃 붕괴)
- 색: 제목 강조=브라운 `#7B401F`, 표헤더=`#5B9BD5`, 출처회색=`#787878`

## 1. 아키텍처: 두 경로 (Route B 채택)

목표(차트·표=고정크기 이미지 / 텍스트=네이티브 편집)를 달성하는 두 경로:

### Route A — 커스텀 레이아웃 placeholder (더 "정석", 그러나 수동 마스터 필요)
슬라이드 마스터에 그림 placeholder 레이아웃을 손으로 만들고 `insert_picture()`. ⚠️ "그림(Picture)" 타입이어야 하며 "콘텐츠(Content/Object)" placeholder 는 python-pptx `insert_picture()` 불가.

### ★ Route B — base 프레임 배경 + 코드 배치 (채택)
**base_slideNN.png 가 이미 "데이터가 빠진 깨끗한 프레임"** (영문헤더·KIS로고·면책·페이지번호만, 확인 완료). 이걸 그대로 활용하면 **수동 마스터 제작이 불필요**하다.

```python
sl = prs.slides.add_slide(blank_layout)
sl.shapes.add_picture(base_png, 0, 0, W, H)          # 배경 프레임(풀블리드)
tb = sl.shapes.add_textbox(left, top, w, h)          # 네이티브 편집 텍스트
tb.text_frame ...                                     # 제목/불릿/코멘트/출처
sl.shapes.add_picture(chart_png, left, top, w, h)    # 고정크기 차트·표 이미지
```
- 결과: 차트·표만 이미지, **제목·불릿·코멘트·출처는 클릭 편집**. base 자체의 정적 라벨(영문헤더 등)은 배경이라 유지(불변).
- 장점: 수동 PowerPoint 작업 0, 좌표는 기존 compose() 값 재사용, 코드로 완결.
- 폰트: 텍스트박스 Pretendard → **pptx 임베딩 필요**.
