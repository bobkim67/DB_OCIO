# DB OCIO 웹 대시보드 — 탭별 기능 정리

> 2026-07-09 기준. React(web/) + FastAPI(api/) 구성, 포트 8020 단일 서버.
> 대상 펀드 9개 (07G02, 07G03, 07G04, 08K88, 08N33, 08N81, 08P22, 2JM23, 4JM12) + 07G07(=07G04 KB투자풀 C-F 클래스 별칭).

## 공통

- 상단 펀드 선택기 (그룹 → 펀드), 선택 상태는 전 탭 공유.
- 탭 keep-alive: 탭 전환 시 각 탭의 조회 조건/기간 상태 유지.
- 데이터 소스: 사내 MariaDB 4개 스키마 (dt=펀드 원장, SCIP=시장 데이터, solution=분류/MP/SAA, cream=제로인).
- 색상 규칙: 상승=코랄, 하락=스틸블루 (Bloomberg 스타일 변형, ACE 디자인 토큰).

## 1. Overview

- **KPI 카드**: 설정일, 기준가, 순자산(NAV), 설정액, 기간 설정/해지, YTD·기간수익률 (연환산 토글 지원).
- **누적수익률 차트**: AP(펀드) vs BM(벤치마크) 또는 SAA 합성지수. BM 없는 펀드는 SAA 목표비중 합성 (해외지수 T-1×환율 반영).
- **MDD(최대낙폭) 차트**.
- **기간별 수익률 표**: 1D/1W/1M/3M/6M/1Y/YTD/설정후 — 달력월 기준(relativedelta), 사내 DT 시스템 수치와 일치 검증됨. 종료일 앵커 변경 가능.
- **Excel export**: 수익률/지표 시트 + 차트 포함 다운로드.
- 설정후 수익률 분모 = 기준가 1000 (DT 규약 일치, 검증 완료).

## 2. 편입종목(PDF)

- **자산군 스택바 + 도넛/테이블**: 8분류 (국내주식/해외주식/국내채권/해외채권/대체투자/FX/모펀드/유동성). 모펀드 보유 펀드는 look-through(1단계 전개) 토글.
- **기준일 조회**: 과거 일자 스냅샷 조회 (주말/공휴일은 직전 영업일). 조회 버튼 적용 방식.
- **컴플라이언스 게이지**: 펀드별 실제 가이드라인 기준 —
  - 08K88: 자산군별 밴드 (해외주식 56±12 / 국내주식 24±8 / 채권 ±2%p)
  - 2JM23: 위험자산 ≤80%, 유동성 ≥2% / 4JM12: 위험자산 ≤50%, 환헤지 한도
  - 07G04: 하위펀드(ISP/RSP) 주식·위험자산 한도
  - SAA 펀드(08N33/08N81/08P22): SAA 목표 대비 비교 (SAA 이하=초록/초과=빨강 음영, 판정 없음)
- **주식 분석**: PER×EPS성장 2D 산점도 (보유 주식 vs 지수 프록시), 지역/스타일 틸트.
- **채권 듀레이션**: 보유 채권 ETF 듀레이션 버블 (운용사 공시 기반).
- **종목/자산군 수익률 차트**: 선택 종목 1년 수익지수 + 매수/매도 마커 + 편입비중 보조축.
- 환매정산중 경고 배지 (환매대금 미지급금 반영 기간 표시).

## 3. 거래내역

- **마스터 컨트롤**: 기준(자산군↔종목) 토글 + 기간 프리셋(MTD/1/3/6M/연초/설정후/custom) — 탭 내 전 차트 공통 적용.
- **거래내역 표**: 종목별 매수/매도/순매수 요약(좌) + 일별 세부내역(우, 펼치기). 해외 종목은 행별 체결환율로 원화 환산 (참고값 주석 표기). BA정산/환전/콜론 등 정산성 거래 구분 라벨.
- **일별 비중 영역차트**: 자산군/종목 기준, 거래 마커(매수▲/매도▼) + 거래 요약 툴팁. 영업일 필터.
- **FX 포지션 차트**: 달러선물 순매도 비중 추이 (4JM12).
- **종목/자산군 수익률 차트**: SCIP 가격 기반 수익지수(시작=100) + 거래 마커 + 비중 레이어. 자산군 모드는 비중가중 바스켓 지수. 드래그 줌 y 자동맞춤, 구간 변화율 측정 도구.

## 4. 성과분석 (Brinson)

- **Brinson 3-Factor 성과요인 분석**: Allocation / Selection / Cross — 일별 경로의존 누적, 사내 R 프로덕션과 0bp 일치 검증 (골든 테스트 18케이스).
- **KPI 카드**: AP/BM/초과수익률(연환산 병기) + 설정액/NAV/기준가 스냅샷(기간변동).
- **위험지표**: 연율화 변동성, MDD, 샤프비율(무위험=KIS CD), IR, 트래킹에러 — AP vs BM.
- **BM/SAA 구성 표**: 벤치마크(또는 SAA) 지수별 목표비중·기여수익률 (경로의존 분해, 합=BM 수익률 정확 일치).
- **자산군별 효과 표 + 워터폴**: 자산군별 비중(±%p vs BM)·기여·Allocation·Selection.
- **수익률 분석 패널**: 전체(AP·BM 누적+초과 영역) / Allocation / Selection 모드, 자산군 드롭다운.
- **옵션**: 자산군 분류방법 1~4 (기본: 펀드별 자동), SAA 소스(등록/proxy) × 비중방식(고정/drift) 토글, 기간별 효과표(월/분기), Excel export.
- BM 없는 펀드는 solution.saa_bm_components 등록 SAA 로 동일 분해 수행.

## 5. 운용보고

- **운용보고(매크로)**: 월/분기/반기 시장 코멘트 (승인 최종본만 표시). 자산군별 문단, 근거 claim/evidence(원천 리서치) 토글, 참여자별 의견(4인 debate), 관련 지표 차트.
- **운용보고(펀드)**: 펀드별 운용 코멘트 — 시장 코멘트 + 해당 펀드 PA/보유/거래 기반. 종목 편출입 사실 검증 반영.
- 코멘트 소스: 증권사 리서치(naver_research) + Outlook 리포트 메일(broker_mail) + monygeek 블로그. 뉴스 미사용.

## 6. Admin

- 시장 debate 실행 → 검수/수정 → 승인(final) 워크플로우.
- 펀드 코멘트 생성/검수/승인 (거래내역·비중 변화 테이블 참조).
- claim/evidence 추적 그래프, coverage metrics, wiki context pack 미리보기.
- ⚠️ 현재 인증 없음 — 내부망 전용 전제. 외부 노출 시 인증/프록시 필수.

## 백엔드 특기사항

- **캐시**: 인메모리 TTL 6h + 디스크 영속(.cache/db_cache.sqlite, .cache/brinson/*.pkl). 서버 기동 시 백그라운드 워밍업.
- **성능**: Brinson 콜드 계산 펀드당 ~1–2분(FoF 더 김), 이후 캐시 조회 0.1s 수준.
- **데이터 갱신 시각**: 거래=당일 18시 / 기준가·보유=익일 새벽 3시 / SCIP 시장데이터=T-1.
- **리서치 배치**(market_research/): 서빙과 분리된 일일 배치 (수집→claim→wiki→debate). 대시보드 구동에는 불필요하나 운용보고 조회 모듈이 코드를 import 하므로 패키지에 포함.
